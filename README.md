# 모험가의 검과 솥

모바일에서 작동하는 판타지 생존 텍스트 TRPG의 초기 플레이어블 프로토타입입니다.

## 포함된 기능

- 여섯 능력치(힘, 민첩, 지능, 카리스마, 건강, 지혜)와 종족 보정
- 탐험 중 확률 이벤트 및 능력치 판정
- 턴 기반 전투, 치명타, 회피, 도주, 전리품
- 마물 식재료와 중복 사용·독성·해독 태그를 반영한 요리
- HP, 기력, 포만감, 상태 이상, 인벤토리
- 설치 가능한 PWA 기본 구성

## 실행

정적 웹 서버에서 `index.html`을 여세요. 예를 들어 VS Code Live Server 또는 GitHub Pages/Cloudflare Pages로 배포할 수 있습니다. 서비스 워커는 `file://` 직접 열기에서는 작동하지 않을 수 있습니다.

3. 퀘스트 상태, NPC 평판, 지역 지도
4. 브라우저 저장 및 계정 기반 클라우드 세이브
